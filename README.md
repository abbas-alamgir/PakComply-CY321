# PakComply: An automated data protection compliance assessment and management tool

Course: CY321 Secure Software Design
Project ID: 32101

## Overview
This project proposes the design of an automated data protection compliance assessment and management tool for organizations to evaluate their degree of compliance with Pakistan’s Data Protection Bill 2023.
The tool would analyze an organization’s data processing practices, privacy policies and procedures, consent processes, data collection and retention practices, and security controls in relation to the requirements of the Data Protection Bill 2023.
## Capabilities
It would be able to identify areas of non-compliance and recommend remediation measures, maintain a record of compliance checklists and supporting evidence, and generate compliance reports.
